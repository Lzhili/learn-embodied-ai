#### 1. 一句话记住它

**雅可比矩阵 (Jacobian Matrix, $J$)** 是一个"翻译器"，在**关节世界**和**手（末端）世界**之间来回翻译：

- **关节世界**：每个电机转了多少度 ($q$)、转多快 ($\dot{q}$)、要出多大力矩 ($\tau$)
- **手的世界**：手到了哪里 ($x$)、动多快 ($v$)、手上能施加多大的力 ($F$)

想让手往右走 1 厘米，电机该转几度？手抓住重物要撑住，电机扭矩该给多大？—— 都要靠它来翻译。

---

#### 2. 为什么它是"桥梁"？

我们在前几个文档学习了**位置**（运动学）和**力/力矩**（动力学）。雅可比矩阵在微分层面连接了这两个领域，具体是两座"桥"：

##### 2.1 速度方向：关节速度 → 末端速度

$$v = J(q) \dot{q}$$

读作：**手的速度 = 雅可比矩阵 × 关节转速**。

> 生活例子：手肘弯一点，指尖划一个大弧线；手腕转一点，指尖只动一小点。同样转 $1°$，不同关节让指尖走的路完全不一样。雅可比矩阵就是把这些"不一样"打包成一张表，告诉你"第 $i$ 个关节转一点，手会往哪个方向动多少"。

##### 2.2 力方向：末端受力 → 关节力矩（动力学的入口）

$$\tau = J^T(q) F$$

注意这里用了 **$J$ 的转置**（$J^T$，把矩阵行和列对调）。这个关系来自**虚功原理**（本质上就是能量守恒：手做的功 = 关节做的功）。

> 为什么是转置？一个直觉：速度走"前进"方向，力走"返回"方向，转置正好让能量在两边相等。这是机器人学里非常漂亮的一个对称性。

> **注意**：对于平面 2R 机械臂，若采用完整位姿速度 $[\dot{x}, \dot{y}, \dot{\phi}]^T$，则末端广义力应写为 $F=[f_x, f_y, m_z]^T$（二维力 + 末端力矩），维度要对应。

如果没有雅可比矩阵，我们就无法根据末端想要的速度反推关节转速，也无法根据末端抓取的负载计算关节电机需要多大的力矩。

---

#### 3. 核心定义：其实就是"求导"

对于一个 $n$ 自由度的机器人，关节变量为 $q = [q_1, \dots, q_n]^T$，末端位姿可写为 $x = f(q)$（即正运动学）。

雅可比矩阵就是**对这个函数求导**：

$$J(q) = \frac{\partial f}{\partial q} = \begin{bmatrix} \frac{\partial x}{\partial q_1} & \cdots & \frac{\partial x}{\partial q_n} \\ \vdots & \ddots & \vdots \\ \end{bmatrix}$$

> 不用被 $\partial f/\partial q$ 吓到，意思就是："**关节角度每变一点点，手的位置变多少**"。
>
> 类比：位置对时间求导是速度；这里位置对**关节角**求导，得到的就是"关节角变化 → 末端位置变化"的比率表。

#### 5. Python 代码验证：计算 2 连杆机械臂的雅可比

使用 `sympy` 符号推导来自动生成平面 2R 机械臂的完整位姿雅可比（$3 \times 2$）。

```Python
import sympy as sp
import numpy as np

def calculate_jacobian_2link():
    # 1. 定义符号
    theta1, theta2 = sp.symbols('theta1 theta2')
    l1, l2 = sp.symbols('l1 l2')

    # 2. 正运动学方程 (末端 x, y 与姿态角 phi)
    # x = l1*c1 + l2*c12
    # y = l1*s1 + l2*s12
    x = l1 * sp.cos(theta1) + l2 * sp.cos(theta1 + theta2)
    y = l1 * sp.sin(theta1) + l2 * sp.sin(theta1 + theta2)
    phi = theta1 + theta2

    # 位姿向量: [x, y, phi]^T
    pose = sp.Matrix([x, y, phi])
    
    # 关节变量向量
    q = sp.Matrix([theta1, theta2])

    # 3. 计算雅可比矩阵 J = d(pose)/d(q), 维度为 3x2
    J = pose.jacobian(q)

    print("--- 完整符号形式的雅可比矩阵 J (3x2) ---")
    sp.pprint(J)

    # 4. 数值验证 (奇异点测试)
    # 完整 J 为 3x2 非方阵，不能直接取 det(J)。
    # 对平面 2R 位置任务，常用其线速度子矩阵 Jv(前两行)判断奇异性。
    # 当 theta2 = 0 时 (手臂完全伸直)，Jv 行列式应为 0。
    J_func = sp.lambdify((theta1, theta2, l1, l2), J, 'numpy')
    
    # 测试: l1=1, l2=1, theta1=0, theta2=0 (伸直)
    J_val = J_func(0, 0, 1, 1)
    Jv_val = J_val[:2, :]
    det_Jv = np.linalg.det(Jv_val)
    rank_J = np.linalg.matrix_rank(J_val)
    
    print("\n--- 数值验证 (手臂伸直 theta2=0) ---")
    print(f"完整雅可比矩阵 J:\n{J_val}")
    print(f"线速度子矩阵 Jv:\n{Jv_val}")
    print(f"det(Jv) (接近0表示位置奇异): {det_Jv}")
    print(f"rank(J) = {rank_J} (用于判断完整雅可比列秩是否下降；小于2才表示列秩退化)")
    print("注: 位置任务的奇异性以 Jv 为准（例如 det(Jv) 是否接近 0）。")

    # 5. 力映射示例: tau = J^T * F
    # F = [fx, fy, mz]^T, 对应平面力与末端力矩
    F = np.array([10.0, 5.0, 1.0])
    tau = J_val.T @ F
    print("\n--- 力/力矩映射示例 ---")
    print(f"末端广义力 F = {F}")
    print(f"关节力矩 tau = J^T F = {tau}")

calculate_jacobian_2link()
```

> 代码干了三件事：
> 1. **推导 J**：写出 x、y、φ 关于 θ₁、θ₂ 的公式，自动求导得到 J（3 行 2 列）。
> 2. **测奇异点**：当 θ₂ = 0（手臂完全伸直）时 `det(Jv) = 0`——手臂伸直后手没法再往"手臂方向"前进，少了一个自由度，这叫**奇异位形**。
> 3. **力映射**：给一个末端力 $F = [10, 5, 1]$，算关节需要出多少力矩 $τ = J^T F$。

---

#### 6. 总结

| 关系 | 公式 | 方向 | 用途 |
|------|------|------|------|
| 速度映射 | $v = J(q)\dot{q}$ | 关节 → 末端 | 反推电机转速 |
| 力映射 | $\tau = J^T(q) F$ | 末端 → 关节 | 算电机力矩 |

- **雅可比矩阵 = 正运动学的导数**：关节角微变 → 末端位姿微变。
- **转置 $J^T$** 用来把"力"传回来，源于虚功原理（能量守恒）。
- **奇异位形**（如手臂伸直）会让 J 的行列式为 0，末端失去某个方向的运动能力。
- 没有它，机器人既"动不起来"（算不出转速），也"干不了活"（算不出力矩）。
