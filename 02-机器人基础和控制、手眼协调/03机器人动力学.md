#### 1. 简介

动力学研究机器人运动与产生该运动所需的力/力矩之间的关系。它分为：

- **正动力学:** 给定力矩，计算加速度/运动轨迹。
- **逆动力学:** 给定运动轨迹（位置、速度、加速度），计算所需关节力矩（用于控制）。

> **通俗理解:** 运动学只回答「关节转多少度 → 手爪到哪儿」，**只看位置、不管力气**；动力学多问一句：「要让机器人这么动，每个关节得使多大劲（力矩）？」
>
> - **正动力学** = 给定力矩 → 会怎样运动（用于仿真）
> - **逆动力学** = 给定想走的轨迹 → 需要多大力矩（**用于控制，最常用**）
>
> 打个比方：逆动力学就像开车时先想好「5 秒内从 0 加到 100」，再反算出「油门要踩多深」。

最常用的建模方法是 **拉格朗日法 (Euler-Lagrange)**，它基于能量守恒。

#### 2. 核心公式

拉格朗日函数 $L$ 定义为系统总动能 $K$ 与总势能 $P$ 之差：

$$L(q, \dot{q}) = K(q, \dot{q}) - P(q)$$

> **`q` 和 `$\dot{q}$` 是什么？** 它们是拉格朗日力学里的标准记号：
>
> - **$q$ —— 广义坐标（位置）**：描述系统「处于什么位置/姿态」的变量。机器人里就是**所有关节的角度**，如 6 自由度机械臂 $q = (q_1, q_2, \dots, q_6)$。叫「广义」是因为它不一定是直角坐标 $(x,y,z)$，只要能量唯一确定系统状态的变量都行（旋转关节是角度，移动关节是位移）。
> - **$\dot{q}$ —— 广义速度**：$\dot{q} = \frac{dq}{dt}$，即 $q$ 对时间求导。机器人里就是**每个关节的角速度**。
>
> 规律：点号越多，求导次数越多——`q`（0 个点）= 位置，$\dot{q}$（1 个点）= 速度，$\ddot{q}$（2 个点）= 加速度。对照第 4 节单摆代码：$q \leftrightarrow$ `theta`，$\dot{q} \leftrightarrow$ `theta_dot`，$\ddot{q} \leftrightarrow$ `theta_ddot`。

> **为什么用能量？** 直接对机器人做受力分析太痛苦。拉格朗日法换个思路：**不盯力，盯能量**。它基于能量守恒——动能 $K$（运动携带的能量）减去势能 $P$（高度携带的能量），剩下的就是「可用于运动的那部分净能量」。

动力学方程（欧拉-拉格朗日方程）：

$$\frac{d}{dt} \left( \frac{\partial L}{\partial \dot{q}_i} \right) - \frac{\partial L}{\partial q_i} = \tau_i$$

> 这个方程说白了就是：**能量对「速度」和「位置」的变化率，决定了需要多少力矩 $\tau$**。它是动力学的「万能公式」，套进去就能自动导出运动方程。

最终通常整理为标准的机器人在动力学形式：

$$M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) = \tau$$

- $M(q)$: 惯性矩阵 (Mass Matrix)
- $C(q, \dot{q})$: 科里奥利力和离心力项
- $G(q)$: 重力项

> 无论什么机器人，最后都能整理成上面这个模样，左边三项对应三种「费力」：
>
> - **$M(q)\ddot{q}$（惯性项）**：让机器人**加速**要花的力——推一辆静止的车，越重越难推动。
> - **$C(q,\dot{q})\dot{q}$（科氏力/离心力项）**：机器人**运动时**因旋转产生的力——坐旋转木马，转得越快越往外甩。
> - **$G(q)$（重力项）**：克服**重力**要花的力——手臂平举着比垂着更费力。
>
> 三项加起来 = 需要输入的力矩 $\tau$，这就是逆动力学的最终答案。

#### 3. 架构流程 (Mermaid)

```Mermaid

    Start[定义系统参数: 质量m, 长度l, 惯量I] --> Energy[计算能量]
    Energy --> K[动能 Kinetic Energy]
    Energy --> P[势能 Potential Energy]
    K & P --> L[构造拉格朗日函数 L = K - P]
    L --> EL_Eq[应用欧拉-拉格朗日方程]
    EL_Eq --> Derive[符号推导/微分]
    Derive --> Torque[获得力矩方程 Tau]
    Torque --> Matrix[整理为 M, C, G 矩阵形式]
```

#### 4. Python 代码验证 (SymPy 符号推导)

动力学推导非常繁琐，使用 Python 的符号计算库 `sympy` 可以完美演示这一过程。以下演示推导一个简单**单摆**的动力学方程。

> **核心思想:** 手推公式容易出错，这里让电脑用**符号微积分**自动完成推导。先看代码块，再读下方的逐步解读。

```Python
import sympy as sp

# 1. 定义符号
t = sp.symbols('t')
m, l, g = sp.symbols('m l g', real=True, positive=True)
theta = sp.Function('theta')(t)  # 关节角度随时间变化

# 定义速度 (theta_dot) 和 加速度 (theta_ddot)
theta_dot = theta.diff(t)
theta_ddot = theta_dot.diff(t)

# 2. 计算能量
# 动能 K = 1/2 * m * v^2。对于单摆，v = l * angular_velocity
v = l * theta_dot
K = sp.Rational(1, 2) * m * v**2

# 势能 P = m * g * h。假设最低点势能为0，则 h = l * (1 - cos(theta))
# 或者简单定义坐标原点在转轴，y轴向上，则 h = -l * cos(theta)
h = -l * sp.cos(theta)
P = m * g * h

# 3. 拉格朗日函数 L
L = K - P

# 4. 欧拉-拉格朗日方程
# d/dt (dL/d_theta_dot)
dL_dthetadot = sp.diff(L, theta_dot)
term1 = sp.diff(dL_dthetadot, t)

# dL/d_theta
term2 = sp.diff(L, theta)

# 力矩 tau = term1 - term2
tau = term1 - term2

# 5. 简化并打印结果
equation = sp.simplify(tau)
print("--- 自动推导的动力学方程 (Tau = ...) ---")
sp.pprint(equation)

print("\n--- 提取各项 ---")
# 对于单摆: M*q_ddot + G = 0 (无阻尼情况)
# 我们期望看到 M = m*l^2, G = m*g*l*sin(theta)
print(f"惯性项 (对应 theta_ddot): {equation.coeff(theta_ddot)}")
# 注意：sympy提取非线性项比较复杂，这里人工观察打印结果即可验证
# 理论结果应为: m * l**2 * theta_ddot + m * g * l * sin(theta)
```

**代码逐步解读：**

1. **定义符号**：`theta = sp.Function('theta')(t)` 把摆角 $\theta$ 定义成「随时间变化的函数」（字母而非数字），这样才能做符号求导；`theta_dot`、`theta_ddot` 分别是对 $t$ 求一阶、二阶导，即角速度 $\dot{\theta}$ 和角加速度 $\ddot{\theta}$。

2. **算动能 K**：单摆的线速度 `v = l * theta_dot`（杆长 × 角速度），套进高中物理的 $K = \tfrac{1}{2}mv^2$。

3. **算势能 P**：`h = -l * cos(theta)` 是把转轴当原点、摆锤高度随角度变化的表达式，再套 $P = mgh$。

4. **套欧拉-拉格朗日方程**：这四行是把公式原封不动翻译成代码——
   $$\tau = \frac{d}{dt}\left(\frac{\partial L}{\partial \dot{\theta}}\right) - \frac{\partial L}{\partial \theta}$$
   其中 `term1` 是「先对 $\dot{\theta}$ 求偏导、再对时间求全导」，`term2` 是「对 $\theta$ 求偏导」，两者相减即得力矩 $\tau$。

5. **验证结果**：理论结果应为
   $$\tau = m\,l^2 \ddot{\theta} + m\,g\,l\,\sin\theta$$
   对照标准形式 $M(q)\ddot{q} + C(q,\dot{q})\dot{q} + G(q) = \tau$：惯性项 $M = ml^2$，重力项 $G = mgl\sin\theta$，且**单摆没有科氏力项 $C$**。`equation.coeff(theta_ddot)` 能自动把 $ml^2$ 这个系数抠出来，验证推导正确。
